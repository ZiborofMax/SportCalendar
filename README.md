# SportCalendar

Promo Sports Hub prototype: sports calendar, daily sports intelligence, source-aware tournament cards, campaign planning, segment filters, and a season matrix view.

Public site:
https://ziborofmax.github.io/SportCalendar/

## Files

- `index.html` - application shell
- `styles.css` - layout and UI styles
- `app.js` - calendar data, filtering, dialogs, daily snapshot
- `data/generated-events.js` - generated API sync output
- `scripts/sync-sports-events.mjs` - TheSportsDB season sync script

## Data update

The prototype includes a daily content snapshot and a generated sync report from TheSportsDB.
